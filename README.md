# VoloNehoda/homebrew-tap

```sh
brew install --cask volonehoda/tap/etherlynx-battery
```

If Homebrew asks you to trust the tap first: `brew trust --tap volonehoda/tap`.

| Cask | App |
|---|---|
| `etherlynx-battery` | [Etherlynx Battery](https://github.com/VoloNehoda/etherlynx-battery) — menu bar battery monitor with charge limit, power flow and alerts |
